## A focused foundation for interface work

Combric keeps styling, behavior, and framework integration deliberately
separate. Build with the browser-native CSS contract, add React components when
useful, and opt into the Tailwind v4 adapter only when it fits your project.

<div class="combric-home-principles">
  <article>
    <h3>Native CSS first</h3>

  <article>
