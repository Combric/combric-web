| Package             | Stable contract                                     | 1.5 release state            |
| ------------------- | --------------------------------------------------- | ---------------------------- |
| `@combric/tokens`   | Typed tokens and CSS variables                      | Stable `1.5.1`, published    |
| `@combric/fonts`    | Optional Fontsource variable-font CSS preset        | Stable `1.5.1`, published    |
| `@combric/icons`    | Iconoir-derived React, CSS, SVG, and typed metadata | Stable `1.5.1`, published    |
| `@combric/layout`   | Framework-independent CSS layout                    | Stable `1.5.1`, published    |
| `@combric/menu`     | Composable React navigation and menu systems        | Stable `1.5.1`, published    |
| `@combric/react`    | React 19 component catalogue                        | Stable `1.5.1`, published    |
| `@combric/tailwind` | Optional Tailwind v4 adapter                        | Stable `1.5.1`, published    |
| `@combric/cli`      | Optional setup and diagnostics                      | Stable `1.5.1`, published    |
| `@combric/guard`    | Optional read-only consumer checker                 | Stable `1.5.1`, published    |
| `@combric/core`     | Empty private repository boundary                   | Excluded from public release |

The nine public packages use synchronized version `1.5.1` and are published on npm.
The release-quality check installs these exact versions from the public npm
registry in an isolated consumer fixture; it does not use framework source,
workspace links, or local tarballs.

`@combric/fonts` is an opt-in consumer package. COMBRIC-WEB documents it but
does not load it globally; consumers choose the preset or their own font
provider through the typography primitives.
