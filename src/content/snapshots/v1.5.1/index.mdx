# Combric v1.5.1 Menu Systems

This is the published **Combric 1.5.1 — Menu Systems** documentation.
The nine public packages are available from npm at `1.5.1`, and
`/docs/latest/` points to this stable snapshot.

Browse the [Menu systems reference](/docs/v1.5.1/menu/), the
[Icons reference](/docs/v1.5.1/icons/), then see the [component catalogue](/docs/v1.5.1/components/actions/button/)
for the React slot contracts. The [Typography guide](/docs/v1.5.1/foundations/typography/)
documents `@combric/fonts` as an opt-in consumer preset; it is not loaded by
this documentation site.
