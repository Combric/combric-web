Standard CSS is a first-class Combric path.

```css
@import "@combric/tokens/css";

.panel {
  color: var(--combric-color-text);
  background: var(--combric-color-surface);
  padding: var(--combric-space-4);
  border-radius: var(--combric-radius);
}
```

For layout classes, import `@combric/layout/css`. For React components, a single
`@combric/react/css` import includes layout and tokens.

## Foundation surface

The preview and copyable source below use only canonical token variables. The
general structural `--combric-radius` remains zero in Metriq; published
components use their role-specific radius tokens.
