---
title: Installation
description: Install the published Combric 1.2.0 packages.
---

This is the published `v1.2.0` documentation snapshot. The public Combric
packages are synchronized at stable version `1.2.0` on npm.

## React components

```sh
npm install @combric/react@1.2.0 react@^19 react-dom@^19
```

React and React DOM `>=19.0.0 <20` are peer dependencies.

## Tokens only

```sh
npm install @combric/tokens@1.2.0
```

## Framework-independent layout

```sh
npm install @combric/layout@1.2.0
```

## Optional Tailwind adapter

```sh
npm install @combric/tailwind@1.2.0 tailwindcss
```

Tailwind CSS must satisfy `>=4.3.0 <5`. Combric does not require the CLI,
Tailwind, or source-copy installation.
