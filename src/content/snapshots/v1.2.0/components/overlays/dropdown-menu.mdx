## Motion

Dropdown content fades and translates/scales by default. Use
`DropdownMenuContent`'s `className` with `data-state` and `data-side` to replace
the visual motion, or set `transition: none` and `animation: none` on that class
to opt out locally. Exit presence follows the computed CSS completion. Reduced
motion is automatic. See the
[Motion Foundation](/docs/v1.2.0/foundations/motion/).
