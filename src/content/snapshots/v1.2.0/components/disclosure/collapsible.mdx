## Motion

Collapsible content animates its measured block size by default. Use
`CollapsibleContent`'s `className` for custom CSS or a local `transition: none`
opt-out. Reduced motion is automatic. See the
[Motion Foundation](/docs/v1.2.0/foundations/motion/).
