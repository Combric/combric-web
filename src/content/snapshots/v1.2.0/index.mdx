# Combric v1.2.0 Motion candidate

This is an unpublished candidate preview for **Combric 1.2.0 — Motion &
Animation System**. It is not a stable release, and no 1.2.0 package is
available from npm. The published stable release remains 1.1.1; `/docs/latest/`
continues to point to that stable snapshot until publication is separately
approved.

Review the [Motion Foundation](/docs/v1.2.0/foundations/motion/) and its
[component catalogue](/docs/v1.2.0/components/actions/button/).
