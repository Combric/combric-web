## Motion

Dialog content and backdrop fade in/out by default with a subtle content scale;
no extra setup is needed beyond `@combric/react/css`. Use `DialogContent`'s
`className` for custom CSS or to disable motion on this Dialog alone. Reduced
motion is automatic. See the
[Motion Foundation](/docs/v1.4.0/foundations/motion/).
