## Motion

Skeleton uses a continuous pulse by default with `motion.duration.slow`. Its
existing `className` hook supports consumer CSS; reduced motion stops the pulse
automatically. See the
[Motion Foundation](/docs/v1.3.0/foundations/motion/).
