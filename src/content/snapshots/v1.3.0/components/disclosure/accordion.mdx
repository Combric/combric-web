## Motion

Accordion content animates its measured block size by default after the native
stylesheet is loaded. Customize `AccordionContent` through `className`, or use
a CSS class with `transition: none` for a local opt-out. Reduced motion is
automatic. See the [Motion Foundation](/docs/v1.3.0/foundations/motion/).
